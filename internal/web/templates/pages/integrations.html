Home Assistant

Two directions. Sodapop can post to a webhook when you check in, and an automation can post a pour back with a token.

Inbound token

An automation can post a pour to POST /hooks/ha/{token} with a JSON body. Send gtin or slug to pick the soda, and an optional rating from 0 to 20 in quarter stars. The token is shown once, when you create it, and only a hash is kept.
